# OmniTools

**Practical browser-based tools, zero uploads.**

OmniTools is a free, fast, static collection of everyday online utilities — image tools, SEO tools, developer tools, text tools and more. Every tool runs entirely on the client side: your files and text are processed in your browser and never uploaded to a server.

Live site: <https://jamamjadalone.github.io/omnitools/>

## Features

- ⚡ **Instant** — no installs, no accounts, no server round-trips
- 🔒 **Private by design** — all processing happens in your browser
- 💸 **Free** — no paywalls, watermarks, or daily limits
- 📱 **Responsive & accessible** — keyboard navigation, ARIA labels, semantic HTML, dark mode
- 🧩 **Data-driven** — the homepage, search, category pages and related-tools lists are generated from a single `data/tools.json`
- 🔍 **SEO-ready** — sitemap, JSON-LD structured data, Open Graph tags, and clean per-tool URLs
