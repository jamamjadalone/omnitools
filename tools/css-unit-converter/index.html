About this tool

Enter a CSS value and unit to see its equivalent in all other common CSS units. Adjust the base font size and viewport dimensions to match your project's settings.

How to use it

  1. Set your base font size (default 16px) and viewport dimensions.
  2. Enter the value and select the source unit.
  3. All converted values appear instantly in the output panel.

Features

  • Converts between px, em, rem, vw, vh, pt, and %
  • Configurable base font size
  • Configurable viewport dimensions
  • Live instant conversion

Frequently asked questions

em is relative to the parent element's font size, while rem is relative to the root (html) font size.

1pt equals 1/72 of an inch. The conversion assumes 1in = 96px (standard CSS assumption).
