About this tool

__ABOUT__

How to use it

  1. Pick the stock platform you are submitting to from the dropdown.
  2. Upload your image with the dropzone or file picker.
  3. Read the automatic checks — each one shows pass, warning or fail with the exact requirement.
  4. Work through the manual checklist for things only you can verify (logos, faces, watermarks).
  5. Use the summary note to fix any failing check before submitting.

Features

  • Platform presets for Adobe Stock, Shutterstock, Freepik and Envato
  • Automatic resolution, format, transparency, aspect ratio and size checks
  • Clear pass / warning / fail status with the specific requirement shown
  • Manual submission checklist for non-automatable rules
  • Overall score plus a summary note that lists exactly what to fix
