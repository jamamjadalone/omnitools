About this tool

Compare two pieces of text and instantly see what changed. Added lines are highlighted in green, removed lines in red, and unchanged lines remain neutral.

How to use it

  1. Paste the original text on the left.
  2. Paste the modified text on the right.
  3. Click Compare texts.
  4. Differences are highlighted in both panels.

Features

  • Side-by-side comparison
  • Added lines highlighted in green
  • Removed lines highlighted in red
  • Works with any text length
