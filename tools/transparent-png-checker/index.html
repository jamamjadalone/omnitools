About this tool

__ABOUT__

How to use it

  1. Drop a PNG (or WebP) onto the dropzone.
  2. The tool scans every pixel for an alpha channel below 255.
  3. A clear verdict tells you whether transparency exists and what percentage of the image is transparent.
  4. Use this to confirm your file is truly a transparent PNG before submission or publishing.
  5. Pair it with the Background Edge Checker to inspect the quality of the transparent edges.

Features

  • Pixel-level alpha channel analysis
  • Clear has-transparency / no-transparency verdict
  • Percentage and fully-transparent pixel stats
  • Image preview on a checkerboard background
  • Fully client-side
