Text to Speech

Convert text to speech using your browser's built-in voices.

Status: Ready. Enter text and click Speak.

About this tool

Uses the Web Speech API to convert text to speech in your browser. Choose from available system voices, adjust rate and pitch for natural-sounding output.

How to use it

  1. Enter or paste text in the input area.
  2. Select a voice from the dropdown.
  3. Adjust rate and pitch as desired.
  4. Click Speak to hear the text read aloud.

Features

  • Uses system voices via Web Speech API
  • Adjustable speech rate and pitch
  • Pause and stop controls
  • Works offline with some voices

Frequently asked questions
