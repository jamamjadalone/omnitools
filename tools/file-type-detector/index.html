About this tool

__ABOUT__

How to use it

  1. Drop one or more files onto the dropzone, or click to browse.
  2. The tool reads the first bytes of each file (the magic number) to identify the real format.
  3. Compare the detected type against the file extension.
  4. A mismatch warning means the file was renamed or converted incorrectly — fix it with the right tool before uploading anywhere.
  5. Re-check each file after converting it to confirm the new extension matches.

Features

  • Magic-byte detection for 25+ common formats (images, documents, archives, audio, video, executables)
  • Extension vs. actual format mismatch detection
  • Batch drop and multi-file inspection
  • Hex preview of the file signature
  • 100% client-side — your files never leave your device
