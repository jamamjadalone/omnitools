About this tool

Paste any block of text — an email thread, a webpage's contents, a spreadsheet export — and this tool scans it for anything that matches a valid email address pattern, then lists each unique match.

How to use it

  1. Paste your text into the input box.
  2. Click Extract emails.
  3. Review the de-duplicated list of results.
  4. Copy all results or download them as a .txt file.

Features

  • De-duplicates repeated addresses automatically
  • Copy all results with one click
  • Download results as a plain text file
  • Runs entirely in your browser
