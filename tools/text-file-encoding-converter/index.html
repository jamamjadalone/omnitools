About this tool

__ABOUT__

How to use it

  1. Load a text file with the file picker.
  2. Confirm the source encoding — the tool auto-detects UTF-8 vs UTF-16 from the BOM or content.
  3. Choose the target encoding and whether to include a BOM.
  4. Review the preview panel to confirm the text looks right.
  5. Click Convert & download to save the re-encoded file.

Features

  • Auto-detection of UTF-8 and UTF-16 from BOM
  • Convert between UTF-8, UTF-16 LE/BE and Latin-1
  • BOM toggle for Windows compatibility
  • Live text preview after conversion
  • Client-side only
