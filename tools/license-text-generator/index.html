About this tool

__ABOUT__

How to use it

  1. Choose a license — MIT, Apache 2.0 or GPL-3.0.
  2. Enter the copyright holder name and the year.
  3. Click Generate license.
  4. Review the full legal text with your details inserted.
  5. Download it as a LICENSE file and place it in your repo root.

Features

  • Complete text of MIT, Apache 2.0 and GPL-3.0
  • Copyright holder and year filled in automatically
  • Copy or download as a LICENSE file
  • Handy per-license summary of what it allows
  • Client-side generation
