How to use it

  1. Paste your raw keyword dump — commas, newlines, spaces and duplicates all fine.
  2. Choose the output format (comma-separated, lines, quoted or CSV).
  3. Toggle dedupe, sorting and lowercasing as needed.
  4. Click Format keywords.
  5. Copy the clean list or download it as a file.

Features

  • Handles any messy separator — commas, newlines, tabs, spaces
  • Duplicate removal with case-insensitive matching
  • Alphabetical sorting
  • Four output formats including CSV
  • Fully client-side
