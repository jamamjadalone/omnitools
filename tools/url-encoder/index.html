About this tool

Encode special characters in URLs to make them safe for transmission, or decode percent-encoded strings back to readable text.

How to use it

  1. Paste a URL or string into the input area.
  2. Click Encode to percent-encode it, or Decode to decode it.
  3. Copy the result.

Features

  • Standard URI encoding (RFC 3986)
  • Encodes spaces, special chars, and non-ASCII characters
  • One-click encode and decode
  • Works with full URLs or query strings

Frequently asked questions
