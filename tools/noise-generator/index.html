Noise Generator

Generate white, pink, or brown noise for focus, sleep, or relaxation.

Choose a noise type and press Play.

About this tool

Generate ambient noise in your browser using the Web Audio API. White noise has equal energy at all frequencies, pink noise has reduced higher frequencies (softer), and brown noise drops off even more steeply (deep, rumbling).

How to use it

  1. Select a noise type: White, Pink, or Brown.
  2. Adjust the volume slider.
  3. Click Play to start the noise.
  4. The waveform visualization updates in real time.

Features

  • White, pink, and brown noise types
  • Smooth volume control
  • Real-time waveform visualization on canvas
  • Fully generated in-browser using Web Audio API
  • No external audio files needed
