About this tool

How to use it

  1. Pick your framework or stack from the dropdown.
  2. Enter your app name.
  3. Click Generate .env.
  4. Copy the template or download it as a .env file.
  5. Fill in the real values, then save as .env (and never commit it to git).

Features

  • Stack-specific templates for 9 common frameworks
  • Commented variable descriptions for each key
  • Sensible defaults for ports, environments and databases
  • Copy or download as a real .env file
  • Client-side generation
