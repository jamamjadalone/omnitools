About this tool

Enter a regular expression and a test string to see live matches highlighted in the output. Capture groups are displayed individually so you can inspect each part of the match.

How to use it

  1. Type your regex pattern (without the slashes) in the Pattern field.
  2. Set flags like g, i, or m in the Flags field.
  3. Enter or paste your test string in the Test string area.
  4. Matches are highlighted instantly and capture groups shown below.

Features

  • Live matching as you type
  • Match highlighting in the output
  • Capture group display
  • Configurable flags (g, i, m, s, u)
