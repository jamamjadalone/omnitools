About this tool

__ABOUT__

How to use it

  1. Paste your package.json into the input.
  2. Click Validate.
  3. The tool checks JSON validity, required fields, version format and dependency syntax.
  4. Each check shows pass, warning or fail with a clear message.
  5. Fix any issues, re-paste and re-validate until it is clean.

Features

  • JSON syntax validation with helpful errors
  • Checks required fields: name, version, description, main, scripts, license
  • Validates semver version strings
  • Flags common issues in dependency names and versions
  • Fully client-side
