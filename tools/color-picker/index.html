Color Picker

Full color picker with HEX, RGB, and HSL values. Pick any color and get all formats instantly.

Color information will appear here.

About this tool

Pick any color using the color input or type a HEX value directly. The tool shows the color in HEX, RGB, and HSL formats with a live preview.

How to use it

  1. Click the color input to open the system color picker, or type a HEX value directly.
  2. The color preview, RGB, and HSL values update automatically.
  3. Click the Copy buttons to copy any format to your clipboard.

Features

  • Live color preview swatch
  • HEX, RGB, and HSL output formats
  • One-click copy for each format
  • Type HEX values directly for precise input
