About this tool

Image Compressor uses the HTML5 Canvas API to re-encode your photo at a lower quality setting, cutting file size while keeping the image sharp enough for web use. Everything happens locally in your browser tab — the image is never uploaded anywhere.

How to use it

  1. Drag and drop an image onto the drop zone, or click it to choose a file.
  2. Adjust the quality slider to balance file size against visual quality.
  3. Watch the before/after file size update live in the preview.
  4. Click Download compressed image to save the result.

Features

  • Supports JPG, PNG and WebP input files
  • Live before/after file size comparison
  • Adjustable quality from 10% to 100%
  • 100% client-side — no uploads, no waiting on a server
  • Works offline once the page has loaded
