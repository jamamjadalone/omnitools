About this tool

Convert any integer from 1 to 3999 into Roman numerals, or paste Roman numerals to get the integer value. Supports the standard modern Roman numeral system.

How to use it

  1. Enter a number (1–3999) or Roman numeral (e.g. XIV).
  2. Click To Roman or To Number.
  3. Copy the result.

Features

  • Integer to Roman numeral conversion (1–3999)
  • Roman numeral to integer conversion
  • Case-insensitive Roman numeral input
  • Input validation
