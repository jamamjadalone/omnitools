How to use it

  1. Drop one or more JPG files onto the dropzone.
  2. The tool re-encodes each image, writing only the pixel data and none of the EXIF/GPS/ICC metadata.
  3. Review the log to see each file processed.
  4. Click Download cleaned images to get everything in a ZIP.
  5. Check the File Size Batch Checker to confirm the cleaned files are smaller.

Features

  • Removes GPS, camera and software metadata
  • Batch processing of many JPGs at once
  • Smaller file sizes after cleaning
  • ZIP export of all cleaned images
  • Fully client-side
