About this tool

This area calculator supports three common geometric shapes: rectangles (length × width), circles (πr²), and triangles (½ × base × height). It also calculates the perimeter for each shape.

How to use it

  1. Select the shape you want to calculate.
  2. Enter the required dimensions (width/height, radius, or base/height).
  3. Choose a unit of measurement if desired.
  4. Click Calculate Area to see the result.

Features

  • Supports rectangles, circles, and triangles
  • Calculates both area and perimeter
  • Multiple unit options
  • Precise calculations with decimal support
  • Instant results

Frequently asked questions

Rectangle: A = w × h, Circle: A = πr², Triangle: A = ½ × b × h.

The unit is just a label for display. The calculation uses the numeric values you enter. Just make sure all dimensions use the same unit.
