About this tool

__ABOUT__

How to use it

  1. Type or paste your text into the input.
  2. Word, character, sentence and reading-time counts update live.
  3. The platform limits panel shows how you compare to Instagram, X/Twitter and YouTube description limits.
  4. Each limit shows your current usage as a progress bar and remaining budget.
  5. Edit your text until it fits the target platform.

Features

  • Live word, character and sentence counting
  • Reading time estimate
  • Platform limits for Instagram, X/Twitter and YouTube descriptions
  • Visual progress bars with remaining budget
  • Fully client-side
