String Hash Generator

Generate MD5, SHA-1, SHA-256, and SHA-512 hashes from any string.

Enter text and click Generate.

About this tool

Generates cryptographic hashes of your input string using the Web Crypto API. Supports SHA-256, SHA-384, and SHA-512. MD5 and SHA-1 are computed using a JavaScript implementation.

How to use it

  1. Enter or paste the text you want to hash.
  2. Click Generate Hashes.
  3. Click any hash to copy it to clipboard.

Features

  • SHA-256, SHA-384, SHA-512 via Web Crypto API
  • MD5 and SHA-1 via JavaScript implementation
  • Click-to-copy on each hash
  • Instant computation

Frequently asked questions

Web Crypto API does not support MD5 or SHA-1 for security reasons. These are computed using a JS polyfill.
