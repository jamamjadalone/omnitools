About this tool

Translate plain text into International Morse Code and vice versa. Supports A–Z, 0–9 and common punctuation marks like period, comma, question mark and more.

How to use it

  1. Type or paste text (or Morse code) into the input box.
  2. Click Text → Morse or Morse → Text.
  3. The translation appears in the output panel.
  4. Copy the result with one click.

Features

  • Full A–Z and 0–9 support
  • Common punctuation: . , ? ! ' " / : ; - ( )
  • Bidirectional: text to Morse and Morse to text
  • One-click copy
