HTML Entity Encoder

Encode and decode HTML entities with instant conversion between text and entity representations.

About this tool

Encode special characters into HTML entities for safe embedding in HTML documents, or decode HTML entities back to plain text.

How to use it

  1. Paste or type your text in the plain text panel.
  2. Click Encode to convert special characters to HTML entities.
  3. Click Decode to convert entities back to plain text.
  4. Copy the output with the Copy button.

Features

  • Encodes < > & " and all non-ASCII characters
  • Decodes numeric (&#60;) and named (&lt;) entities
  • Bidirectional encode/decode
  • One-click copy support
