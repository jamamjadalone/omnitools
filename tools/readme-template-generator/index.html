__ABOUT__

How to use it

  1. Enter your project name, a one-line description and your GitHub username.
  2. Choose a license and the sections you want.
  3. Click Generate README.
  4. Review the markdown preview — badge URLs are built from your GitHub details.
  5. Copy it or download as README.md and drop it in your repo root.

Features

  • Professional structure: badges, features, install, usage, contributing, license
  • Badge row built from your GitHub username and repo name
  • License badge and section matched to your selection
  • Copy or download as markdown
  • Client-side generation
