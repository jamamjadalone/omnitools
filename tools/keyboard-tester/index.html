About this tool

A visual keyboard tester that highlights keys as you press them. Useful for checking if all keys on your keyboard are working correctly.

How to use it

  1. Click anywhere on the page to focus it.
  2. Press any key on your physical keyboard.
  3. The corresponding virtual key lights up.
  4. Check the last key and key code display.

Features

  • Full QWERTY keyboard layout
  • Real-time key highlighting
  • Shows key name and code
  • Reset button to clear highlights
