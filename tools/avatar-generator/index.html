Avatar Generator

Generate avatar images from initials with custom colors.

About this tool

Create placeholder avatars from initials with custom background and text colors. Perfect for user profiles, placeholder images, and team directories.

How to use it

  1. Enter a name (first letters become initials) or type initials directly.
  2. Pick background and text colors.
  3. Choose size and shape, then click Generate.
  4. Download the result as PNG.

Features

  • Auto-extracts initials from full names
  • Custom background and text colors
  • Circle or rounded square shapes
  • Download as PNG at multiple sizes
