Image to ASCII Art

Convert uploaded images to ASCII art text.

Upload an image and click Convert.

About this tool

Upload any image and convert it to ASCII art text. Adjust the output width and choose from different character sets for different styles of ASCII art.

How to use it

  1. Upload an image using the file picker.
  2. Adjust the width and character set to your liking.
  3. Click Convert and copy the result.

Features

  • Multiple character sets for different looks
  • Adjustable output width
  • Grayscale-based brightness mapping
  • Works with PNG, JPG, GIF, and more

Frequently asked questions
