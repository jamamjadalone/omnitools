About this tool

Generate a properly formatted robots.txt file for your website. Block all crawlers, restrict specific paths, add a sitemap reference, and include custom rules for specific bots.

How to use it

  1. Enter paths you want to block (one per line, e.g. /admin/).
  2. Add your sitemap URL if you have one.
  3. Add any custom rules for specific user agents.
  4. Click Generate, then copy or download the file.

Features

  • Blocks all crawlers by default with custom disallow paths
  • Optional sitemap reference
  • Support for custom per-bot rules
  • Download as robots.txt file
