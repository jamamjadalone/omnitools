About this tool

Build standard 5-field cron expressions using simple input fields or quick presets. The expression and a human-readable description update instantly as you change any field.

How to use it

  1. Use the quick presets to start from a common schedule, or edit the fields directly.
  2. Each field accepts *, specific numbers, ranges (1-5), lists (1,3,5), or steps (*/5).
  3. The cron expression and description update in real time.
  4. Copy the expression with the Copy button.

Features

  • Visual 5-field cron builder
  • Quick preset buttons for common schedules
  • Live human-readable description
  • Copy-to-clipboard support
