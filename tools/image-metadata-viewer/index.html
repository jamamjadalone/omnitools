Image Metadata Viewer

View EXIF and other metadata from uploaded images.

Upload an image to view its metadata.

About this tool

Upload any image to view its embedded metadata including dimensions, file size, format, and any available EXIF data like camera model, date taken, and GPS coordinates.

How to use it

  1. Upload an image using the file picker.
  2. View the metadata displayed on the right.

Features

  • Displays image dimensions, file size, and format
  • Reads basic EXIF data from JPEG files
  • Image preview
  • No data uploaded — runs in browser

Frequently asked questions

If the image contains GPS EXIF data, the coordinates will be displayed.

Many apps and services strip EXIF data. Screenshots and edited images typically don't contain camera metadata.
