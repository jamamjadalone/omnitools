About this tool

Design your database schema visually by adding tables and fields with types and constraints. Export the complete CREATE TABLE SQL when done.

How to use it

  1. Enter a table name and add fields with types.
  2. Mark fields as primary key or NOT NULL as needed.
  3. Click Add Table to save the table.
  4. Add more tables, then click Export SQL.

Features

  • Multiple table support
  • Common SQL types (INTEGER, VARCHAR, TEXT, etc.)
  • Primary key and NOT NULL constraints
  • One-click SQL export

Frequently asked questions

It generates standard SQL that works with MySQL, PostgreSQL, and SQLite with minor adjustments for AUTO_INCREMENT vs SERIAL.
