About this tool

__ABOUT__

How to use it

  1. Paste or type your meta description.
  2. Click Check & preview (or it updates live).
  3. See exactly how it renders in a Google-style result preview.
  4. Read the character count, word count and status badge.
  5. Use the advice panel to tune the length toward the recommended 150–160 characters.

Features

  • Live Google-style search result preview
  • Character and word counting
  • Clear under / ideal / over status with recommendations
  • Visual truncation indicator on overflow
  • Client-side, no data sent anywhere
