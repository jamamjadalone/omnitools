About this tool

Estimates your connection speed by timing how fast your browser can download random data. Results are approximate and depend on server load and other factors.

How to use it

  1. Click Start Test to begin.
  2. Wait for the download test to complete.
  3. View your estimated speed in Mbps.
  4. Test again for more accurate results.

Features

  • Download speed estimation
  • Connection type detection
  • Effective type and downlink info
  • No data sent to external servers

Frequently asked questions

This is an approximation. For accurate results, use dedicated speed test services that test against nearby servers.
