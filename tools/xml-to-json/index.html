About this tool

Paste any XML document and convert it to a JSON object. Elements, attributes, and text content are all mapped to their JSON equivalents.

How to use it

  1. Paste your XML into the input area.
  2. Click Convert to JSON.
  3. Review the resulting JSON and copy it.

Features

  • Preserves XML attribute names
  • Handles nested elements
  • Multiple same-name siblings become arrays
  • Formatted JSON output
