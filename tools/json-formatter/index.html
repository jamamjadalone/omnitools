About this tool

Paste raw JSON to instantly pretty-print it with consistent indentation, minify it down to a single line, or catch syntax errors with a clear message pointing at the problem.

How to use it

  1. Paste your JSON into the input panel.
  2. Click Format to pretty-print it, or Minify to compress it.
  3. If there's a syntax error, the message under the input explains what to fix.
  4. Copy the result with the copy button.

Features

  • Pretty-print with 2-space indentation
  • One-click minify to a single line
  • Clear syntax error messages
  • Copy-to-clipboard for the formatted result
