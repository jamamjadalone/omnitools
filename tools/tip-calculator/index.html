About this tool

A quick and easy tip calculator that lets you set a custom tip percentage, see the total, and split the bill evenly among any number of people.

How to use it

  1. Enter the bill amount in the input field.
  2. Adjust the tip percentage with the slider or use the preset buttons.
  3. If splitting, enter the number of people.
  4. The results update automatically in real time.

Features

  • Real-time calculation as you type
  • Preset tip buttons for common percentages
  • Custom tip percentage via slider (0-50%)
  • Bill splitting for up to 50 people
