About this tool

__ABOUT__

How to use it

  1. Drop your .zip file onto the dropzone.
  2. The archive is opened in your browser and its contents are listed.
  3. Tick the files you want, or leave all selected.
  4. Click Extract all as ZIP to re-bundle the chosen files, or Download selected to grab the ticked ones directly.
  5. Files with a check appear as a list with sizes for easy review.

Features

  • Browse ZIP contents without installing anything
  • Select individual files or extract everything
  • Per-file size display
  • Handles nested folder paths
  • JSZip-powered, fully client-side
