About this tool

Generates git commit messages following the Conventional Commits specification. Helps maintain clean, readable, and machine-parseable commit histories.

How to use it

  1. Select a commit type (feat, fix, etc.).
  2. Optionally add a scope.
  3. Write a short description of the change.
  4. Click Generate Message and copy the result.

Features

  • Follows Conventional Commits spec
  • Supports all standard commit types
  • Optional scope and body fields
  • Breaking change indicator

Frequently asked questions
