About this tool

A browser-based metronome that generates precise click sounds using the Web Audio API. Set your tempo, choose a time signature, and practice with a reliable beat.

How to use it

  1. Set the BPM using the slider or preset buttons.
  2. Choose a time signature (beats per bar).
  3. Click Start to begin the metronome.
  4. The beat dots light up to show the current beat in the bar.

Features

  • BPM range from 20 to 300
  • Multiple time signatures (2/4 through 7/4)
  • Visual beat indicator
  • Two sound options: click and wood block
  • Precise timing using Web Audio API scheduling

Frequently asked questions

The Web Audio API provides sample-accurate timing, while JavaScript timers are imprecise and affected by main-thread congestion.

From 20 BPM (very slow) to 300 BPM (extremely fast), covering all practical musical tempos.
