About this tool

This tool samples pixels from your image on an HTML5 canvas and clusters similar colors together to surface the most dominant shades — handy for matching a brand palette or picking accent colors for a design.

How to use it

  1. Upload an image using the drop zone.
  2. Choose how many colors you'd like to extract.
  3. Click any swatch to copy its hex code to your clipboard.
  4. Use the palette to inform your design or brand colors.

Features

  • Adjustable palette size from 3 to 10 colors
  • One-click copy for every hex code
  • Works with JPG, PNG and WebP images
  • Fully client-side — your image never leaves the browser

Frequently asked questions

The tool samples pixels across the image and groups visually similar colors together, then reports the most common resulting shades.

Each swatch shows both the hex code and RGB value beneath it.

Larger images give more representative sampling, but very large images may take a moment longer to process.
