Color Converter

Convert between HEX, RGB, and HSL color formats.

About this tool

A versatile color converter that lets you input a color in any format — HEX, RGB, or HSL — and instantly see the equivalent values in all three formats, along with a live preview.

How to use it

  1. Enter a color in any field: HEX, RGB, or HSL.
  2. All other fields update automatically.
  3. Use the color preview or native picker to visually select colors.
  4. Click Copy buttons to grab the value you need.

Features

  • Convert between HEX, RGB, and HSL
  • Live color preview
  • Native browser color picker integration
  • One-click copy for each format

Frequently asked questions

HEX (#rrggbb), RGB (rgb(r, g, b)), and HSL (hsl(h, s%, l%)) — the three most common web color formats.

The HEX input accepts both #rrggbb and #rgb shorthand. The RGB and HSL fields accept numeric values.
