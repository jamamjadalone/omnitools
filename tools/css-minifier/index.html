About this tool

Paste your CSS to minify it by removing comments, whitespace, newlines, and unnecessary characters. Useful for reducing file sizes in production.

How to use it

  1. Paste your CSS into the source panel.
  2. Click Minify to compress it.
  3. View the size reduction stats and copy the result.

Features

  • Removes comments and whitespace
  • Collapses multiple spaces and newlines
  • Preserves string literals (content values)
  • Shows original vs minified size comparison
