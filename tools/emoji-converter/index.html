About this tool

Convert between emoji characters, HTML numeric entities (like 😀), hex entities (like 😀), and Unicode code points (like U+1F600). Useful for web development and debugging encoding issues.

How to use it

  1. Paste emoji characters, HTML entities, or code points.
  2. Click the appropriate conversion button.
  3. Copy the result.

Features

  • HTML decimal entity conversion (&#128512;)
  • HTML hex entity conversion (&#x1F600;)
  • Unicode code point conversion (U+1F600)
  • Supports all emoji including compound emojis
