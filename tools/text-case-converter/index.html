About this tool

Paste any text and instantly convert it to the case format you need — useful for cleaning up headlines, variable names, or copy that was typed in the wrong case.

How to use it

  1. Paste your text into the input box.
  2. Pick a case format from the buttons.
  3. The converted text appears instantly.
  4. Copy the result with one click.

Features

  • UPPERCASE, lowercase, Title Case and Sentence case

  • Live conversion as you type
  • One-click copy
