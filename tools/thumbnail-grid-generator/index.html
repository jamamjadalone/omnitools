About this tool

__ABOUT__

How to use it

  1. Choose how many columns and how large each thumbnail should be.
  2. Decide whether to show file names under each thumbnail.
  3. Drop the images you want to review onto the dropzone.
  4. The tool builds a contact sheet and previews it.
  5. Click Download contact sheet to save it as a printable JPG.

Features

  • Auto-grid layout with configurable columns
  • Optional file-name labels for easy identification
  • Live preview before download
  • Handles up to 50 images per sheet
  • Fully client-side
