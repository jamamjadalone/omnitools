About this tool

This generator uses your browser's cryptographically secure random number generator (not a predictable pseudo-random function) to create passwords, so results are suitable for real account security.

How to use it

  1. Set your desired password length with the slider.
  2. Choose which character sets to include: uppercase, lowercase, numbers, symbols.
  3. Click Generate for a new password.
  4. Copy it and store it in a password manager.

Features

  • Uses the Web Crypto API for true randomness
  • Adjustable length from 4 to 64 characters
  • Toggle uppercase, lowercase, numbers and symbols independently
  • Built-in strength indicator
