Best practices

  • Describe the image specifically and factually.
  • Keep it under ~125 characters.
  • Include your target keyword naturally, not awkwardly.
  • Decorative images can use empty alt text (alt="").

About this tool

__ABOUT__

How to use it

  1. Describe what the image shows in plain words.
  2. Choose the context — general, product, tutorial or decorative.
  3. Click Generate alt text.
  4. Review the suggested text and edit it to match your page.
  5. Copy it into the alt attribute of your image.

Features

  • Context-aware alt text suggestions (general, product, tutorial)
  • Decorative-image guidance with empty alt handling
  • Keyword-aware phrasing from your description
  • Copy-to-clipboard for easy pasting
  • Runs on-device — no AI API, no uploads
