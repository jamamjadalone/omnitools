About this tool

Paste a JSON Web Token to decode and view its header, payload, and signature in a readable format. All decoding happens locally in your browser.

How to use it

  1. Paste a JWT token into the input area.
  2. Click Decode.
  3. View the header, payload, and signature in separate panels.
  4. Timestamps in the payload (like iat, exp) are displayed in readable date format.

Features

  • Decodes header, payload, and signature
  • Formatted and syntax-highlighted JSON output
  • Automatic timestamp conversion to readable dates
  • Works entirely in your browser
