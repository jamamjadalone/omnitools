How to use it

  1. Type your page title.
  2. Optionally add your site name, which appears after the title in results.
  3. Click Check & preview for a live Google-style preview.
  4. Read the character count and approximate pixel width.
  5. Use the advice panel to keep the title in the recommended 50–60 character range.

Features

  • Live Google-style search result preview
  • Character count with the 50–60 character guideline
  • Approximate pixel-width estimate (mobile and desktop)
  • Clear status badge with actionable advice
  • Fully client-side
