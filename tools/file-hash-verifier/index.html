About this tool

__ABOUT__

How to use it

  1. Copy the SHA-256 hash shown on the page you downloaded the file from.
  2. Paste it into the Expected hash field.
  3. Drop the downloaded file onto the dropzone.
  4. The tool computes the file's real SHA-256 and compares them.
  5. A match confirms the download is intact; a mismatch means the file is corrupt or tampered with — download it again.

Features

  • SHA-256 verification with Web Crypto
  • Live match / mismatch result with color coding
  • Copyable computed hash
  • Handles hashes pasted with or without a sha256: prefix
  • Fully client-side
