__ABOUT__

How to use it

  1. Pick the output format — JPG, PNG or WebP.
  2. Adjust the quality slider (quality only applies to JPG and WebP).
  3. Drop one or more images onto the dropzone.
  4. Watch the log as each image is converted with its new size shown.
  5. Click Convert & download to get every converted file in a ZIP.

Features

  • Convert between JPG, PNG and WebP
  • Quality control for JPG and WebP output
  • Batch conversion with per-file size log
  • ZIP export of all converted files
  • Fully client-side
