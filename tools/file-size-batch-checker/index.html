About this tool

__ABOUT__

How to use it

  1. Set the size limit in megabytes (defaults to 10 MB).
  2. Drop files or a whole folder onto the dropzone, or click to browse.
  3. Every file is scanned and sorted by size — over-limit files are highlighted in red.
  4. Check the summary stats at the top for counts and total size.
  5. Click Download CSV report to export the full list.

Features

  • Batch size check across hundreds of files at once
  • Custom size limit with clear over/under highlighting
  • Automatic sort by size, biggest first
  • CSV report export for your records
  • Runs 100% in your browser
