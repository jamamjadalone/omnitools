About this tool

__ABOUT__

How to use it

  1. Type your watermark text — add © and your name or brand.
  2. Choose a position, opacity and relative text size.
  3. Drop one or more images onto the dropzone.
  4. A live preview shows the first image with the watermark applied.
  5. Click Download watermarked to export all images in a ZIP.

Features

  • Text watermark with © symbol support
  • Five position presets
  • Opacity and size sliders with live preview
  • Batch watermarking with ZIP export
  • Client-side only
