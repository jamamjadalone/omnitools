About this tool

__ABOUT__

How to use it

  1. Paste your CSV into the input — comma or semicolon separators are auto-detected.
  2. Keep the header checkbox on if the first row is column names.
  3. The columns panel appears; rename any column or drag to reorder.
  4. Click Apply column edits to preview the result.
  5. Copy the cleaned CSV or download it as a file.

Features

  • Auto-detects comma, semicolon or tab separators
  • Rename any column in place
  • Reorder columns by drag-and-drop or arrow buttons
  • Trim whitespace and quote cleanup
  • Copy or download the result as .csv
