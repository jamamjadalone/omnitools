UUID Generator

Generate RFC 4122 v4 UUIDs in bulk, ready to copy or download.

Your UUIDs will appear here.

About this tool

Generates version 4 (random) UUIDs using the browser's built-in cryptographic random number generator, following the RFC 4122 format used across databases, APIs and distributed systems.

How to use it

  1. Choose how many UUIDs you want to generate.
  2. Click Generate.
  3. Copy all of them at once, or click an individual one to copy just that value.

Features

  • Generate 1 to 100 UUIDs at a time
  • RFC 4122 version 4 compliant
  • Copy individually or all at once
  • Download as a plain text file

Frequently asked questions

UUIDs are used as unique identifiers for database rows, API resources, session tokens and more, without needing a central authority to avoid collisions.

Each UUID is generated using crypto.randomUUID() where available, backed by a cryptographically secure random source.

It's astronomically unlikely — version 4 UUIDs have 122 random bits, making accidental collisions practically impossible.
