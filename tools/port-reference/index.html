Frequently asked questions

A port number is a numerical identifier (0-65535) assigned to a specific process or service on a networked computer, used with an IP address for communication.

TCP is connection-oriented and reliable; UDP is connectionless and faster but doesn't guarantee delivery. Many services use TCP, while DNS and some streaming use UDP.
