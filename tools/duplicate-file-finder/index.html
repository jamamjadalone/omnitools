About this tool

__ABOUT__

How to use it

  1. Drop a group of files (or a folder) onto the dropzone.
  2. The tool hashes every file with SHA-256 using your browser's Web Crypto API.
  3. Files sharing an identical hash are grouped as duplicates.
  4. Read the duplicate groups and the total space you could free by removing the extras.
  5. Delete the duplicates in your own file manager — this tool never deletes anything.

Features

  • Exact-match detection via SHA-256 hashing
  • Hundreds of files handled at once, with progress feedback
  • Duplicate groups clearly listed with file sizes
  • Estimate of disk space that could be freed
  • Fully offline and private
