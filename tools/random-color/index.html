Random Color Generator

Generate random colors and build a palette you can export.

About this tool

Generate a palette of random colors for design inspiration. Click any color to copy its value. Export the whole palette as a list or CSS custom properties.

How to use it

  1. Set the number of colors you want in your palette.
  2. Choose the format: HEX, RGB, or HSL.
  3. Click Generate Palette to create new colors.
  4. Click any swatch to copy its value, or use the export buttons.

Features

  • Generate up to 20 random colors at once
  • HEX, RGB, and HSL format support
  • Click a swatch to copy its color value
  • Export as CSS custom properties for easy use

Frequently asked questions

This version generates an entirely new palette each time. You can copy colors you like before regenerating.

The colors are fully random, generated using the Web Crypto API for true randomness across the entire color space.
