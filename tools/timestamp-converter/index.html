About this tool

Convert between Unix timestamps (seconds or milliseconds since epoch) and human-readable dates. See all formats at once — ISO 8601, UTC string, and both timestamp variants.

How to use it

  1. Enter a Unix timestamp (e.g. 1700000000) or a date string (e.g. 2023-11-14).
  2. Click the appropriate conversion button, or use Use Current Time.
  3. All output formats update simultaneously.

Features

  • Supports both seconds and milliseconds timestamps
  • Outputs ISO 8601, UTC, and Unix formats
  • One-click current timestamp
  • Bidirectional conversion
