Letter Frequency Counter

Count the frequency of each letter and word in your text with a visual bar chart.

Enter text to see frequency analysis.

About this tool

Analyse any text to see how often each letter or word appears. The bar chart makes it easy to spot the most and least common characters at a glance.

How to use it

  1. Paste or type text into the input box.
  2. Choose Letters or Words mode.
  3. The chart updates live as you type.

Features

  • Letter frequency and word frequency modes
  • Visual horizontal bar chart with percentages
  • Sorted from most to least frequent
  • Real-time updates as you type
