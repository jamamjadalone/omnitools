QR Code Generator

Turn any link, text or Wi-Fi password into a downloadable QR code.

Supports up to about 100 characters (URLs, short messages, Wi-Fi strings).

About this tool

This tool renders a scannable QR code directly on an HTML5 canvas as you type, using a compact client-side QR encoding routine. Download it as a PNG for print or share it digitally — no server round-trip required.

How to use it

  1. Type or paste the text, URL, or Wi-Fi details you want to encode.
  2. Choose a size and foreground/background color if you'd like to customize it.
  3. The QR code updates live in the preview panel.
  4. Click Download PNG to save it.

Features

  • Live preview as you type
  • Custom foreground and background colors
  • Adjustable output size for print or web
  • Download as a high-resolution PNG
  • Works fully offline once loaded
