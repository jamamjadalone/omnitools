QR Code Generator

Turn any link, text or Wi-Fi password into a downloadable QR code.

Wi-Fi and contact modes build the correct payload for you. Keep the encoded data under about 100 characters for reliable scanning.

About this tool

This tool renders a scannable QR code directly on an HTML5 canvas as you type, using a compact client-side QR encoding routine. Pick the Wi-Fi preset to let your guests join your network by scanning, or the Contact preset to share a vCard. Download the result as a PNG for print or share it digitally — no server round-trip required.

How to use it

  1. Type or paste the text or URL you want to encode, or pick the Wi-Fi or Contact preset and fill in the fields.
  2. Choose a size and foreground/background color if you'd like to customize it.
  3. The QR code updates live in the preview panel.
  4. Click Download PNG to save it.

Features

  • Live preview as you type
  • Wi-Fi preset that generates the correct connection string
  • Contact preset that generates a vCard
  • Custom foreground and background colors
  • Adjustable output size for print or web
  • Download as a high-resolution PNG
  • Works fully offline once loaded
