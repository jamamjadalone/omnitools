About this tool

__ABOUT__

How to use it

  1. Choose what to resize by: dimensions, scale factor, or target file size.
  2. Enter the target values for the chosen mode.
  3. Drop one or more images (or a folder) onto the dropzone.
  4. The tool resizes each image, keeping aspect ratio by default.
  5. Click Download resized images to get everything in a ZIP.

Features

  • Resize by max dimensions, scale percentage, or target file size
  • Batch processing with a progress log
  • Aspect ratio preserved by default
  • JPG, PNG and WebP support
  • All results bundled into a single ZIP
