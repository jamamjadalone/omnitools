About this tool

Paste HTML markup to analyze its heading structure. The tool checks for correct hierarchy (no skipped levels), counts headings, and highlights issues that hurt accessibility and SEO.

How to use it

  1. Paste your HTML into the input area.
  2. Click Check Headings.
  3. Review the heading tree and any issues found.

Features

  • Detects skipped heading levels (e.g. H1 → H3)
  • Shows complete heading tree
  • Counts total headings by level
  • Warns about missing H1 or multiple H1s

Frequently asked questions

Screen readers and search engines use heading hierarchy to understand page structure. Skipped levels confuse both.

Best practice is one H1 per page that describes the page's main topic.
