About this tool

__ABOUT__

How to use it

  1. Enter the DPI value you need (300 is the standard for print).
  2. Drop a JPG onto the dropzone.
  3. The tool reads the current DPI and rewrites the JPEG with your value — pixel dimensions are untouched.
  4. Check the new print size shown in the results.
  5. Click Download with new DPI to save the updated file.

Features

  • Rewrite JPEG DPI/PPI metadata without resampling
  • Reads current DPI from the original file
  • Shows the resulting print size at the new DPI
  • 300 DPI preset with custom values supported
  • Fully client-side
