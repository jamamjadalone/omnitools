Color Blindness Simulator

Simulate deuteranopia, protanopia, and tritanopia on images.

About this tool

Upload an image and see how it appears to people with different types of color vision deficiency. Helps designers create accessible visuals.

How to use it

  1. Upload an image from your device.
  2. Select a simulation type from the buttons.
  3. The canvas updates to show the simulated view.
  4. Download the result if needed.

Features

  • Deuteranopia (red-green, no green cones)
  • Protanopia (red-green, no red cones)
  • Tritanopia (blue-yellow)
  • Download simulated image

Frequently asked questions

These are approximations using color transformation matrices. Real color blindness varies in severity between individuals.
