Dice Roller

Roll multiple dice with different numbers of sides.

—

About this tool

A versatile dice roller for tabletop RPGs, board games, and any situation where you need random dice rolls. Supports any number of dice with any number of sides.

How to use it

  1. Use the quick-roll buttons for common RPG dice, or set custom count and sides.
  2. Click Roll! to roll the dice.
  3. View the total and individual die results.
  4. Roll history is kept during your session.

Features

  • Quick-roll buttons for d4, d6, d8, d10, d12, d20
  • Custom dice count and sides (up to 1000-sided dice)
  • Shows individual die results and total
  • Roll history maintained during the session
  • Uses cryptographically secure random values
