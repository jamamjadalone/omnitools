About this tool

__ABOUT__

How to use it

  1. Name your archive (the .zip is appended automatically if missing).
  2. Drop files or a whole folder onto the dropzone.
  3. Review the file list on the right — folder paths are preserved.
  4. Click Create ZIP.
  5. Your .zip downloads immediately, ready to share or upload.

Features

  • Bundle any number of files into one ZIP
  • Folder structure preserved inside the archive
  • Custom archive name
  • Uses JSZip with DEFLATE compression
  • 100% client-side
