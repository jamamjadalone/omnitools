Convert between length, weight, and temperature units.

About this tool

A fast, offline unit converter supporting the most common length, weight, and temperature units. Results update instantly as you type.

How to use it

  1. Select a category: Length, Weight, or Temperature.
  2. Enter a value in the input field.
  3. Choose the "From" and "To" units from the dropdowns.
  4. The converted result appears immediately.

Features

  • Length: mm, cm, m, km, in, ft, yd, mi
  • Weight: mg, g, kg, oz, lb
  • Temperature: Celsius, Fahrenheit, Kelvin
  • Real-time conversion as you type
  • Fully offline — no data sent anywhere

Frequently asked questions
