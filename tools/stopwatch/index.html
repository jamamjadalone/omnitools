Lap Times

About this tool

A precision stopwatch that tracks time down to the millisecond. Record lap times as you go, and copy the full lap log when you're done.

How to use it

  1. Click Start or press Space to begin timing.
  2. Click Lap to record a lap split without stopping the timer.
  3. Click Stop to pause, then Reset to clear.
  4. Use Copy Laps to copy all recorded lap times.

Features

  • Millisecond-precision timing using requestAnimationFrame
  • Record unlimited lap splits
  • Lap times show split and total
  • Keyboard shortcuts: Space (start/stop), L (lap), R (reset)

Frequently asked questions

It uses requestAnimationFrame for display updates and performance.now() for timing, giving sub-millisecond precision in modern browsers.

The stopwatch uses wall-clock timestamps, so it stays accurate even when the tab is in the background or the display is throttled.
