About this tool

A three-in-one percentage calculator that covers the most common percentage problems: finding a percentage of a number, computing the percent change between two values, and determining what percent one number is of another.

How to use it

  1. Percentage of: Enter the percentage and the number, and the result appears immediately.
  2. Percentage change: Enter the starting and ending values to see the percent increase or decrease.
  3. What percent: Enter two values to find what percent the first is of the second.

Features

  • Three calculators in one tool
  • Real-time results as you type
  • Handles decimals and large numbers
  • Shows positive and negative percentage changes
  • No button needed — results update live
