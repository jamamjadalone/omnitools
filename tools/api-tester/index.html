About this tool

Quickly test any HTTP endpoint by sending requests with custom methods, headers, and JSON bodies. View the response status, headers, and body instantly.

How to use it

  1. Select the HTTP method (GET, POST, PUT, DELETE, PATCH).
  2. Enter the request URL.
  3. For POST/PUT/PATCH, enter a JSON body.
  4. Add optional headers (one per line as Key: Value).
  5. Click Send Request and view the response.

Features

  • Supports GET, POST, PUT, DELETE, PATCH
  • Custom headers and JSON body
  • Status code and response time display
  • Response body and headers viewer

Frequently asked questions

Currently only JSON bodies are supported. Form data and multipart requests are not available.

Requests are limited by your browser's CORS policy. APIs that don't allow cross-origin requests will fail.
