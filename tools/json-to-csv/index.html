About this tool

Paste a JSON array of objects and instantly convert it to comma-separated values. Each object's keys become column headers and each object becomes a row. Download the result as a .csv file.

How to use it

  1. Paste a JSON array of objects into the input area.
  2. Click Convert to generate the CSV.
  3. Review the output, then copy or download it.

Features

  • Handles nested objects by flattening keys
  • Properly escapes commas and quotes in values
  • One-click CSV download
  • Works entirely in the browser
