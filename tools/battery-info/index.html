About this tool

Uses the Battery Status API to display real-time information about your device's battery including charge level, charging state, and estimated time remaining.

How to use it

  1. Open this page on a device with a battery.
  2. The battery info displays automatically.
  3. Click Refresh to update the data.

Features

  • Real-time charge level display
  • Charging/discharging state
  • Estimated time to full/empty
  • Charging time and discharging time

Frequently asked questions

The Battery Status API is not supported on all browsers or devices. Desktop browsers and iOS Safari do not support it.
