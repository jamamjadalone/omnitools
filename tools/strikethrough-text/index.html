About this tool

Wrap your text in Discord/Telegram-style markdown strikethrough formatting using double tildes. Also generates Unicode combining characters for universal strikethrough that works anywhere.

How to use it

  1. Type or paste text into the input box.
  2. Click Generate strikethrough.
  3. Choose between markdown (~text~) or Unicode output.
  4. Copy and paste it wherever you need.

Features

  • Markdown strikethrough (~text~) for Discord/Telegram
  • Unicode combining strikethrough (works anywhere)
  • One-click copy
  • Supports full sentences and paragraphs

Frequently asked questions

~text~ works in Discord, Telegram, GitHub, Reddit and other platforms that support markdown.

Unicode uses combining character U+0336 that renders a strikethrough on each character. It works on most platforms including Instagram, X, and SMS.
