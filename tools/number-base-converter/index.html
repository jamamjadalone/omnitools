About this tool

Type a number in any base and instantly see its representation in binary, octal, decimal, and hexadecimal. Perfect for developers, students, and anyone working with different number systems.

How to use it

  1. Enter a number in the input field.
  2. Select the base of your input number.
  3. Click Convert to see all representations.
  4. Copy the result you need.

Features

  • Converts between binary, octal, decimal, and hex
  • Instant results for all bases at once
  • Input validation with error messages
  • Case-insensitive hex input

Frequently asked questions

Hexadecimal uses 0–9 and A–F (case insensitive).

JavaScript handles numbers up to 2^53-1. Larger values may lose precision.

This tool works with integer values only.
