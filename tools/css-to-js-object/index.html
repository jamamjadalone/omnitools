About this tool

Converts CSS property declarations into JavaScript camelCase style objects or inline style strings. Useful for React inline styles and dynamic styling in JS.

How to use it

  1. Paste CSS properties (without selector) into the input.
  2. Choose output format: Object or Inline style.
  3. Click Convert and copy the result.

Features

  • Converts kebab-case to camelCase
  • Outputs as JS object or inline style string
  • Handles vendor prefixes
  • Proper value quoting

Frequently asked questions

CSS uses kebab-case (font-size) while JavaScript uses camelCase (fontSize). This tool converts between them automatically.
