About this tool

Turn normal text into corrupted-looking glitch or zalgo text by adding random combining Unicode characters above and below each letter. Great for memes, usernames, and creative posts.

How to use it

  1. Type or paste your text into the input box.
  2. Choose a mode: Zalgo, Glitch, or Crazy.
  3. Adjust the intensity slider.
  4. Click Generate and copy the result.

Features

  • Zalgo mode with combining characters
  • Glitch mode with random Unicode substitutions
  • Crazy mode mixing both effects
  • Adjustable intensity from 1 to 10
