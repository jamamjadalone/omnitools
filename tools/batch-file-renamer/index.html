About this tool

__ABOUT__

How to use it

  1. Pick a mode: change the extension, apply a name pattern, or find/replace text in names.
  2. Select one or more files (or an entire folder) with the dropzone.
  3. Configure the options for the chosen mode — prefix, suffix, numbering or the find/replace pair.
  4. Preview the new filenames in the panel on the right.
  5. Click Download renamed files to receive everything in a single ZIP.

Features

  • Three modes: extension change, pattern rename, find/replace
  • Sequence numbering with custom prefix/suffix and zero-padding
  • Option to keep the original extension while renaming the base
  • Live preview of every new filename before you download
  • One-click ZIP export of all renamed files using JSZip
