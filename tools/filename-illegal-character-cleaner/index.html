About this tool

__ABOUT__

How to use it

  1. Type or paste the filename (with extension) into the input.
  2. Pick the platform you are uploading to — this controls which characters are illegal.
  3. Choose the replacement character (a hyphen by default).
  4. Click Clean filename.
  5. Review which characters were replaced in the detail list, then copy the cleaned name.

Features

  • Platform-specific rules for Windows, Mac/Linux, cloud uploads and strict-all
  • Live detail of every character replaced
  • Custom replacement character
  • Protects against reserved names like CON, PRN, NUL
  • Fully client-side

Frequently asked questions

Windows forbids < > : " / \ | ? * and control characters, plus reserved device names like CON, PRN, AUX, NUL, COM1-9 and LPT1-9. The Windows preset handles all of these.

Mac and Linux only forbid the forward slash (/) and null bytes. The tool still replaces other awkward characters for safety but applies the stricter Windows rules only on the Windows preset.
