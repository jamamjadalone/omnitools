About this tool

Convert a date and time from one time zone to another. The tool uses your browser's built-in Intl API to handle timezone offsets correctly, including daylight saving time.

How to use it

  1. Pick a date and time using the date/time picker.
  2. Select the source time zone.
  3. Select the target time zone.
  4. Click Convert to see the converted time.

Features

  • Supports major world time zones
  • Uses the browser's native Intl API for accurate offsets
  • Handles daylight saving time automatically
  • Works offline — no server calls needed
