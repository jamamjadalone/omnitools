How to use it

  1. Tick the presets that match your project — frameworks, OS and editors.
  2. Click Generate .gitignore.
  3. Combined rules appear in the right panel with section headers.
  4. Copy the content or download it as a .gitignore file.
  5. Place the file in your project root before your first commit.

Features

  • 13 presets covering languages, frameworks, OS and editors
  • Multiple presets combined into one file
  • Section headers for readability
  • Copy or download
  • Client-side generation
