About this tool

Generate scannable Code 128 barcodes from any ASCII text. Code 128 is one of the most widely used barcode formats, supporting all 128 ASCII characters. Great for product labels, inventory, and shipping.

How to use it

  1. Enter the text or numbers you want to encode.
  2. Choose a scale for the output size.
  3. The barcode is generated automatically as you type.
  4. Download as PNG or SVG for use in documents or designs.

Features

  • Code 128 encoding (all ASCII characters)
  • Live barcode preview as you type
  • Download as PNG or SVG
  • Adjustable scale for different sizes
  • Fully client-side — no server calls
