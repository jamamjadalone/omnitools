How to use it

  1. Paste or type the text you want to convert — a title, filename or phrase.
  2. Adjust the options: lowercase, strip special characters and choose a separator (hyphen, underscore or none).
  3. The result updates instantly in the panel.
  4. Click Copy result to copy the clean filename or slug.
  5. Scroll the examples panel to see how different inputs are converted.

Features

  • Live conversion as you type
  • Hyphen, underscore or concatenated output
  • Automatic removal of special characters and double separators
  • Handles accented characters (é → e, ñ → n, etc.)
  • Built-in example conversions for reference
