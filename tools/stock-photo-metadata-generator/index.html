Stock Photo Metadata Generator

Paste a short description of your photo and get a platform-ready title, description and keyword list for Adobe Stock, Shutterstock or Freepik submissions.

Starter draft — always review and edit before submitting to any platform. Generated entirely in your browser.

About this tool

__ABOUT__

How to use it

  1. Pick the platform you are submitting to — it adjusts title and description length to the platform's guidelines.
  2. Paste a plain, factual description of the photo — subjects, action, setting, lighting, mood.
  3. Click Generate metadata.
  4. Review the title, description and keywords in the right panel.
  5. Edit anything that is inaccurate, then copy each field into your submission form.

Features

  • Platform-aware title, description and keyword generation
  • Title kept to 10–12 words and description to 40–55 words for Adobe Stock
  • 50-keyword suggestion list built from your description text
  • Copy buttons for each field
  • Runs entirely on-device — no AI API calls, no uploads
